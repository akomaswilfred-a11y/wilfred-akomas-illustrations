## Important image disclosure

The eight artwork previews in `assets/portfolio-studies-ai-generated.png` were generated with AI specifically as portfolio concept images. Replace these previews with original artwork as it becomes available, retaining accurate AI disclosures where applicable.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the repository root to GitHub Pages on pushes to `main`. Enable Pages in repository Settings if GitHub asks for an initial source selection; choose GitHub Actions.
